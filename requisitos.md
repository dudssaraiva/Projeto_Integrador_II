# Buriti Monitor - Requisitos

## Introdução
Este documento apresenta os requisitos do **Buriti Monitor**, uma solução *IoT* destinada ao monitoramento de informações relacionadas à quantidade e à qualidade da água.

## Objetivo do Sistema
Monitorar informações relacionadas à quantidade e à qualidade da água, permitindo o acompanhamento dos dados e a identificação de situações que necessitem de intervenção.

## Escopo
- Coleta de dados;
- Monitoramento;
- Transmissão;
- Visualização;
- Alertas;
- Armazenamento.

## Usuários
1. Administrador
- Gerenciar o sistema;
- Consultar informações;
- Acompanhar alertas.
2. Usuário responsável pelo monitoramento
- Visualizar dados;
- Acompanhar condições da água;
- Verificar alertas;
- Consultar histórico.

## Requisitos funcionais
### RF01 — Coleta de dados
O sistema deverá coletar informações provenientes dos sensores.
### RF02 — Transmissão de dados
O sistema deverá coletar informações provenientes dos sensores.
### RF03 — Visualização dos dados
O sistema deverá permitir a visualização dos dados coletados.
### RF04 — Identificação de alterações
O sistema deverá identificar valores que estejam fora dos parâmetros estabelecidos.
### RF05 — Emissão de alertas
O sistema deverá emitir alertas quando forem identificadas condições que necessitem de atenção.
### RF06 — Armazenamento dos dados
O sistema deverá armazenar os dados coletados para permitir consultas posteriores.

## Requisitos não funcionais
### RNF01 — Usabilidade
A interface deverá apresentar as informações de maneira clara e organizada.
### RNF02 — Segurança
O sistema deverá impedir o acesso de usuários não autorizados às informações restritas.
### RNF03 — Confiabilidade
O sistema deverá realizar a coleta e transmissão dos dados de forma consistente
### RNF04 — Disponibilidade
O sistema deverá permitir o acompanhamento das informações quando os dispositivos e a comunicação estiverem disponíveis.

## Requisitos de hardware
- Dispositivo de processamento;
- Sensores necessários para coleta das informações;
- Componentes eletrônicos necessários para funcionamento do protótipo;
- Fonte de alimentação adequada;
- Meio de comunicação para transmissão dos dados.
  
## Requisitos de software/ usuário
- Sistema de coleta;
- Sistema de processamento;
- Banco de dados;
- Interface de monitoramento;
- Sistema de alertas;
- Comunicação entre dispositivos.
